# cad/ · CAD 模型

此目录存放 SolidWorks 导出的可交换格式模型，供他人直接打印或继续编辑。

## 当前状态：尚未上传

建模正在进行中。**尺寸基准依赖零件实测数据**，见 [`../docs/01-零部件测绘表.md`](../docs/01-零部件测绘表.md)。

## 规划结构

```
cad/
├── step/         可编辑实体（按件号）
├── stl/          打印用网格（按件号）
└── assembly/     整机装配体
```

打印件共 12–13 件，编号 P01–P12，清单见
[`../docs/05-内部堆叠与机构详图.html`](../docs/05-内部堆叠与机构详图.html)。

## 导出约定

| 项 | 约定 |
|---|---|
| 单位 | mm |
| 坐标系 | Z 轴朝上，原点在机身**底面中心** |
| STEP | AP214 |
| STL | 二进制，弦高公差 0.02 mm |
| 命名 | `LD-P01-head-front.step` |

## 打印方向（重要）

导出前请确认模型的**默认朝向即打印朝向**：

- **腿** —— 侧卧（让层纹垂直于受力方向）
- **颈** —— 横躺
- **头壳** —— 后壳朝下、正面朝上

竖着打的腿和颈会在装配时沿层断裂。
