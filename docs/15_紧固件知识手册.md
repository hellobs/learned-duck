> 起因：2026-10-02 晚，连续几轮讨论（热熔螺母配什么螺丝、凸台装不下 M3 沉头、孔该开多大）

## 0. 先建立一条主线：四个问题，按顺序问

做任何一处紧固，问完这 4 个就有答案了，剩下的都是查表：

```
① 这个面看得见吗？        → 决定头型（沉头 / 还是内六角别拧上来）
② 壁够厚吗？              → 决定沉台能不能开、螺母能不能埋
③ 螺纹从哪来？            → 直接成型 / 热熔螺母 / 自攻 / 线套
④ 螺丝够长吗？            → L ≥ 沉台 + 各层壁厚 + 咬合
```

**绝大多数失败，是第 ② 条和第 ④ 条没算**——不是料不够，是不知道要多少。

## 1. 家族地图：先分清这 5 样东西

| 类 | 中文 | 英文 | 本质 | 本项目有没有 |
|---|---|---|---|---|
| **机丝** | 机器螺钉 | Machine Screw | 拧进**已有的螺纹孔**（母材或螺母），不自己攻牙 | ✅ M2 / M3 |
| **自攻钉** | 自攻螺钉 | Self-tapping Screw | 自己**挤/切**出螺纹，拧进预制光孔 | ❌ 没买，但值得知道 |
| **螺栓** | 六角螺栓 | Bolt | 粗杆 + 六角头，通常**配螺母**夹紧两件 | ❌ 只有颈接口那 2×M4 是准这个用法 |
| **热熔螺母** | 热熔铜螺母 | Heat-set Insert | 压进塑料里的**内螺纹基座** | ✅ M2×3×3 / M3×5×4.5 |
| **热熔螺柱** | 热熔螺柱 / 凸台 | Heat-set Standoff | 一体式「定位柱 + 内螺纹」，压进去 | ❌ 没买 |

### 1.1 最容易混的一对：机丝 vs 自攻

| | 机丝（Machine screw） | 自攻钉（Self-tapping） |
|---|---|---|
| 拧进什么 | **现成的螺纹孔** | 一个光孔，边拧边攻 |
| 螺纹截面 | 三角牙（等边） | 尖牙 / 三角牙带刃口 |
| 拧进去要不要导引 | 要（孔得对） | 不要，它自己开路 |
| 拧出后还能再拧吗 | ✅ 可以反复 | ⚠️ 孔会被自己攻大，几次就松 |
| 用在哪 | **所有可拆的、要反复拆的地方** | 一次性封死、不打算拆的地方 |

**判据一句话：要能拆、能反复拧 → 机丝 + 螺母。 一次性的、薄料封口 → 自攻钉。**

塑料件上自攻钉还能干一件热熔螺母干不了的事：**料太薄（<1.5mm），热熔螺母的孔比料还厚**——这时候自攻钉从正面钻进去，靠挤压力咬住，是唯一解。代价是拧两三次孔就松了。

## 2. 型号怎么读

### 2.1 螺丝：`M3 × 10 · 沉头 · 十字 · 粗牙`

| 段 | 读什么 | 影响什么 |
|---|---|---|
| **M3** | 螺纹公称直径（杆径） | 决定**杆孔**多大、配哪个螺母 |
| **10** | **杆长（不含头高）** | 决定够不够长。**买的时候标的这个数就是杆长** |
| 沉头 | 头型 | 决定**沉台**多大、表面凸不凸 |
| 十字 | 槽型 | 十字（电批好拧）/ 一字（老件）/ 内六角（扭矩大、头部小） |
| 粗牙 | 螺距 | 粗牙（标准，M3=0.5）抗振、好拧；细牙密封好、可调预紧 |

> ⚠️ **"M3×10"里的 10 不含头。** 一条 M3×10 沉头，总长 = 10 + 1.65 ≈ 11.65。
> 算长度账的时候用 10（杆），别用 11.65，也别用 8.15 当总长。

### 2.2 热熔螺母：`M3 × 5 × 4.5`

顺序和螺丝**不一样**，先 M3 后 length 再外径：

| 段 | 值 | 含义 |
|---|---|---|
| **M3** | 内螺纹 | → 只能配 M3 螺丝 |
| **5** | 长度（有效螺纹） | → **螺丝杆最多只能吃进去 5mm** |
| **4.5** | 本体大径 / 滚花外径 | → 决定**安装孔打多大** |

**它不决定螺丝头型。** 螺丝头型是被连接件上那个**沉台**定的（见 §3）。

### 2.3 安装孔（这一步才归螺母管）

**孔深公式（比死记数字可靠）：**

```
孔深 = 螺母长度 L_nut + 0.5 ~ 1.0
孔底必须留 ≥ 0.5 实料
```

| 螺母 | 长度 | 孔径 | **孔深** |
|---|---|---|---|
| **M2×3×3** | 3 | Ø3.0 | **3.5** |
| **M3×5×4.5** | 5 | Ø4.2~4.4（推荐 4.3） | **5.5** |

> **本项目 P1 凸台怎么对上这个公式：** 凸台高出脸面 5.5，顶端先开沉台 1.2，
> 沉台底再往下打盲孔 4.3 —— **1.2 + 4.3 = 5.5，两段之和正好等于凸台高**（凸台是从脸面长出来的实心台，没有多余料）。
> 盲孔净深 4.3 里埋长 3 的 **M2×3×3**（公式要求 3.5），富余 1.3 ✓。

**过盈量：塑料件用 0.03~0.08 mm / mm 直径**（M3 取 0.2~0.4 总过盈）。
- 过盈太小 → 压进去会转、会松；
- 打满 Ø4.5 → 过盈为零，铜螺母套进去一动就滑圈。

## 3. 头型全景（★核心：头型由沉台决定）

### 3.1 主流头型对照

| 头型 | 标准 | M2 头径/头高 | M3 头径/头高 | 表面状态 | 用在哪 |
|---|---|---|---|---|---|
| **开槽沉头** | GB/T 68 | 4.0 / **1.2** | 5.5 / **1.65** | ✅ 与面齐平 | 外表面（正脸） |
| **半沉头** | GB/T 69 | ≈4.0 / ≈1.2 | ≈5.5 / ≈1.65 + 圆顶 0.2~0.3 | ✅ 微凸一点 | 外表面（**本项目手上有货**） |
| 盘头（十字） | GB/T 65 | 4.0 / 1.5 | 5.5 / **1.8** | ❌ 头顶是拱的 | 腔内、被别的件盖住的 |
| 圆头 | GB/T 67 | 4.0 / 1.6 | 5.5 / 2.0 | ❌ 凸 | 同上 |
| **内六角圆柱头** | GB/T 70.1 | — | 5.5 / **3.0** | ❌ **凸 3.0** | **腔内承重**（髋、腿关节） |
| 六角头 | GB —— | — | — | ❌ 凸 | 配螺母的夹紧连接 |

### 3.2 三条反直觉的点（这三条吃过多亏）

**① 沉头的头径，远比你以为的大。**
90° 锥面决定了头径 = 1.8~2.1 × 杆径：

| 杆 | M2 | M3 | M4 | M5 |
|---|---|---|---|---|
| 沉头头径 | **4.0** | **5.5** | **8.4** | 9.3 |

M4 沉头头径 **8.4mm**——比杆径大一倍多。这不是标错，是 90° 锥角的几何后果。

**② 所以：薄板上开沉台，会打穿。** ← 这是第 ② 个问题（壁够厚吗）的来源

判据：

```
沉台深度 ≤ 板厚 − 0.5（底要留实料）
沉台半径 + 最小边距 ≤ 可用半宽
```

- 前脸 2.5 厚，开 M2 沉台 1.2 → 剩 1.3 ✓
- 前脸 2.5 厚，开 M3 沉台 1.65 → 剩 0.85，勉强；**再薄一档就废**
- 顶开 Ø5.5 沉台，而凸台只有 Ø5.5 → **整个顶面被挖穿，壁厚归零** → 这就是 `14` §5 那个"杯子凸台"的成因

**③ 沉台宁浅 0.1~0.2，不可深 0.5。**
- 挖浅了：螺丝头顶在孔口沉不下去 → **被连接件被顶起 1.2mm**（本项目 `10` §12 就是这么栽的：法兰被顶起 → 泡棉压不实 → 漏气）
- 挖深了：正面凹一个坑 → 只有外观代价

**所以正确的因果链是：**

```
螺丝头型号 → 需要多大的沉台(Ø/深) → 沉台开在哪个面 → 开得下吗 → 正面能藏住吗
```

螺母只在这一链的最末：给你个能拧的螺纹。

## 4. 长度与咬合（第 ④ 个问题）

```
螺丝杆长 L ≥ 沉台深 k + 螺丝穿过的所有壁厚 Σt + 咬合长度 n
```

- **n（咬合长度）**：螺距 × 4 牙保险。M3 螺距 0.5 → n ≥ 2.0；想要牢就 3.0
- **L 是杆长，不含头**
- 上限：见 §4.2 —— **杆尖后面是空的完全正常**；真正的上限是「别顶穿对面壳 / 别顶死螺母孔底」。

### 4.1 本项目三处算账

| 用途 | 沉台 k | 壁厚 Σt | 咬合 n | 最少 L | 结论 |
|---|---|---|---|---|---|
| **合壳 P1↔P2** | 1.65（在 P2） | P1 2.5 + P2 2 = 4.5 | 2.0 | **8.15** | M3×10 ✓ 富余 1.85 |
| **喇叭法兰** | 1.2（M2） | 脸 2.5 + 凸台（自孔） | 3.0 | **5.4** | **M2×10 富余 2.6** ✓ |
| **橙外罩 P14** | — | 脸 2.5 | 3.0 | **6.7** | **M2×10** ✓（M2×8 富余 1.3，太险） |

> **教训沉淀：三个位置得出同一个答案 M2×10 —— 不是巧合，是这三处都是"薄壁正面藏头"，薄壁本来就喂得饱 M2。**

### 4.2 ★ 杆尖后面（沿螺丝方向）还有很多空间，合适吗？

**一句话：合适，而且是常态。只要空间在「杆尖的那一头 / 杆尖之下」，就没有任何问题。**
塑料壳里几乎不存在「螺丝拧到底还顶着实料」的正常设计——真顶上了，通常是出事了。

先分清你说的"空间"在哪一段（三种完全不同）：

| 空间位置 | 判据 | 结论 |
|---|---|---|
| **① 杆尖之后（末端下面）是空腔** | 杆尖离任何硬面 ≥ 0.5~1.0 mm | ✅ **完全合适**，这就是本节要说的 |
| **② 杆的中段周围是空腔**（螺丝穿过一个大腔） | 杆是刚体，中段没支撑不影响受力 | ✅ 无所谓，**更不影响** |
| **③ 杆尖顶到硬底**（对面壳壁 / 螺母孔底 / 另一个零件） | 越拧越紧、拧不到头 | ❌ **顶死**：塑料会被撑裂、螺纹滑牙、热熔螺母被顶歪（这就是 §2.3 要求孔底留 0.5~1.0 实料的原因） |

**L 的真正上限（不是"别超过螺母长度"，这个说法是错的）：**

```
L_max ≈ 沉台深 k + 螺丝穿过的所有壁厚 Σt + 热熔螺母长度 n_螺母 + 间隙 0.5~1.0
```

超过 L_max 才是"太长"；在 L_max 以内，**杆尖后面剩多少空间都行**。

#### 两个反直觉的点

**(a) 承力几乎全在最前面几牙。** 螺母螺纹的载荷分布：第 1 牙吃 ~30~40%，前 3~4 牙吃掉 ~70~80%，再往里的牙基本不受力。
→ 所以「杆尖后面还有一大截空腔」不但无害，反而**说明没有顶死风险**；
→ 反过来，螺丝杆在螺母里**只咬了 1~2 牙**（L 太短）才是要命的——那种一拧就滑、还容易把热熔螺母带转。

**(b) 咬合长度 ≠ 螺丝杆长。** `M3×10` 的 **10 是杆长**；咬合长度只有杆穿过被连接件之后、真正和螺母螺纹重叠的那一段（≥4 牙 = M3 的 2.0mm）。
买螺丝时你支出的"长度"里，绝大部分是**穿壁厚 + 悬空浪费掉的部分**，只有末尾 2~3mm 在干活。

#### ⚠️ 唯一的特例：自攻钉不能悬空

**机丝（配螺母）杆尖悬空 = 好事；自攻钉杆尖悬空 = 装不上。**

自攻钉没有螺母，它靠杆身自己把塑料挤出螺纹（切削/滚压），所以**杆尖必须先进进料里**才能一路攻过去。
判据反了：自攻钉要求 `L ≥ k + Σt + 攻入深度(≥2~3 牙)`，且杆尖**必须落在实心料上**，落进空腔 = 攻不到底、螺丝松、孔被撑大。

> 所以"能不能留空间"这个问题，**机丝看的是"别顶死"，自攻钉看的是"必须顶到料"** —— 正好相反。

#### 4.2.1 本项目三处复核（都是"杆尖悬空"，都合适）

| 用途 | 螺丝 | 沉台+穿壁 | 杆尖进螺母 | 螺母长 | 杆尖距孔底 | 结论 |
|---|---|---|---|---|---|---|
| 喇叭法兰 | M2×10 | 1.2+2.5 = 3.7 | 6.3 | 3.0 | **~3.3 悬在腔里** | ✅ 不顶死 |
| 橙外罩 P14（腔内拧） | M2×10 | 1.2（腔侧沉台） + 穿脸 2.5 + 穿盖 4 | 咬合 3.0 ≈ 螺母长 3.0 | 3.0 | 杆尖正好到螺母底，**塑料孔底还留 0.5~1.0 实料** | ✅ 不顶死塑料 |
| 合壳 P1↔P2 | M3×10 | 1.65+4.5 = 6.15 | 3.85 | 5.0 | **~1.15** | ✅ 勉强不顶死 |

> 合壳那颗最紧：杆尖离热熔螺母孔底只剩 1.15mm。**别再往上加长**（M3×12 在这里就危险了）——
> 这也是为什么 §4.1 里合壳算出来是 M3×10 而不是更长的规格。

#### 4.2.2 装配后一眼自检

拧到底之后，从后口（或任何能看见杆尖的角度）看一眼：
- 杆尖**没顶到任何东西**、螺丝头能完全沉进沉台 → 合格；
- 螺丝头沉不下去 / 拧到一半就"到底了" → **L 超了**，换短一号，不是换大一号。

## 5. 塑料件里的螺纹：5 种方案怎么选（★本项目的战场）

3D 打印塑料件上要一个螺纹孔，有 5 条路：

| 方案 | 做法 | 最小壁厚 | 可拆次数 | 成本 | 推荐度 |
|---|---|---|---|---|---|
| **① 直接成型** | 打印时就把螺纹打出来 | ≥ 2× 螺纹大径 | 3~5 次后滑牙 | 0 | ⭐⭐ 薄件/非受力 |
| **② 热熔螺母** | 压入内螺纹嵌件 | ≥ 外径 × 0.7 单边（M3 需 ≥1.6） | 多次 | ¥0.05/颗 | ⭐⭐⭐⭐ **本项目主力** |
| **③ 自攻钉** | 从正面钻进光孔自己攻 | 很薄也行（≥0.8） | 2~3 次孔就松 | 有 | ⭐⭐ 一次性封口 |
| **④ 自攻螺母** | 带尖牙的嵌件，拧进光孔（不用加热） | 同② | 多次 | 略贵 | ⭐⭐⭐ 不想带热熔枪时 |
| **⑤ 线套（Helicoil）** | 不锈钢线卷的螺纹套，拧进预丝孔 | 同② | 多次（可修复） | 贵 | ⭐ 修复/高受力 |

### 5.1 选型判据（按顺序判）

```
壁厚 T:
  T ≥ 2.0mm 且 不拆/少拆        → ① 直接成型（零成本）
  T ≥ 1.6mm 且 要拆/受力        → ② 热熔螺母 ← 本项目几乎所有点
  T < 1.6mm                     → ③ 自攻钉 / ④ 自攻螺母 / 干脆用胶+销
  T 很薄 + 完全不想加工         → 用 VHB 胶体 + 圆销定位（见 `12` §2 方案 C）
```

### 5.2 直接成型螺纹的真实参数（PETG）

- 孔打印时**比标称大 0.1~0.2**（PETG 收缩 + 挤出量波动）
- 最小螺纹壁厚（牙顶到零件外沿）**≥ 0.75 × 螺距 × 2** → M3 需 ~1.5mm 实料
- 强度大概是热熔螺母方案的 **1/3**，拧 3~5 次牙就圆了
- **热熔螺母是花 5 分钱换"永远能拆"**，塑料件上几乎永远值得

## 6. 压入件工艺（热熔螺母/螺柱）

| 环节 | 做法 | 坑 |
|---|---|---|
| 工具 | 电烙铁 / 专用热熔枪（配对应尺寸压头） | **别用打火机/喷枪** —— 铜导热快，塑料会熔过头发焦 |
| 温度 | 电烙铁头**贴住螺母端面** 2~3 秒，别一直烤 | 烤久了螺纹孔壁塌、孔径变小，螺丝拧不进 |
| 润滑 | 螺母端面薄薄一层硅油/黄油 | 干压容易卡死在半路 |
| 到位 | 压到**端面与孔口齐平**即可，别再往下捅 | 捅过头 = 背面凸出 = 干涉相邻件 |
| 冷却 | **静置不动到完全冷却**（≥30s） | 塑料软的时候一碰就歪，歪了没法救 |
| 检验 | 冷透后手扭不转、螺丝能沉到底 | 见 §7 |

**压歪了怎么办：** 只有一条路——往里挪 1mm 把孔填平重打。**别硬掰、别补胶再压。**

## 7. 防松（什么时候才需要）

塑料件 + 桌面物件，95% 的情况**不会振松**。只有这 4 种情况要防：

| 情况 | 对策 |
|---|---|
| 会振动 / 会被敲（腿关节、髋） | 尼龙锁紧螺母（Nylock，带尼龙环）/ 螺纹胶 |
| 要频繁拆装 | 别用胶（拆一次就废），用尼龙螺母 |
| 孤单颗、受力大 | 螺纹锁固胶 Loctite 243（中强度，可拆）+ 手工扭矩 |
| 完全不想动 | Loctite 2701（低强度，永久）或热熔胶点封 |

**该知道的三个坑：**
1. **弹垫（弹簧垫圈）在塑料上完全无效** —— 它是为金属刚度设计的，塑料会被压平，等于没垫。
2. **平垫有用**：增加承压面、防止沉头把塑料表面挤出毛边。塑料件上值得加。
3. **尼龙螺母不能用在 >80°C**，PETG 件上没问题。

## 8. 失效图鉴：8 种坏法 + 一眼对策

| 现象 | 原因 | 对策 |
|---|---|---|
| **螺丝头浮在表面、沉不下去** | 沉台挖浅了 / 头型选错（M3 头塞 M2 沉台） | 挖深沉台 0.2~0.3，**或换对头型** |
| **被连接件被顶起一截（不严）** | 同上，螺丝头顶在沉台底/孔口 | 沉台开到能让头顶进去；这是本项目泡棉漏气事故的根源 |
| **塑料件开裂 / 凸台崩了** | 沉台直径 ≥ 凸台直径（壁厚归零） | 换小一号螺丝 / 加粗凸台 / 沉台开到对面的面上 |
| **拧两三次就滑牙转圈** | 直接成型螺纹太薄 / 孔打太大 | 埋热熔螺母 |
| **热熔螺母会转（不随螺丝转）** | 过盈不够 / 孔打大了 | 孔收 0.1mm 重打 |
| **拧不进去、越拧越卡** | 孔径小了 / 螺母歪 / 烤过头孔壁塌了 | 孔扩 0.2；**换位置重打**，别撬 |
| **螺丝杆拧到底就顶死、拧不动** | 太长，杆尖顶到螺母底 | 换短一档（本项目 M2×8 vs M2×10 就是这条线） |
| **孔口出现裂纹（放射状）** | 孔距边太近（< 2× 壁厚） | 孔位外移；热熔螺母尤其会放射裂 |

> **判据记住两条：**
> ① **沉台底到背面留 ≥ 0.5 实料**；
> ② **孔心到边 ≥ 沉台半径 + 1.5**（热熔螺母尤其，它压进去会往外撑裂）。

## 9. SolidWorks 里怎么把这些孔做出来

### 9.1 一个固定点 = 三层同心孔（别混成一层）

| 层 | 给谁 | M2 | M3 |
|---|---|---|---|
| **③ 沉台** | 螺丝头 | Ø4.0 × 深 1.2 | **Ø5.5 × 深 1.65** |
| **② 杆孔（直孔）** | 螺丝杆 | Ø3.0 | **Ø3.2~3.5**（M3 杆齿顶 ≈2.76） |
| **① 螺母安装孔** | 热熔螺母 | Ø3.0 × 深 3.5 | **Ø4.3 × 深 5.5** |

**必须开在正确那一面：**
- 螺丝头在**外表面**（腔内拧进来）→ 沉台开在**外表面**
- 螺丝头在**腔内**（从外表面拧进去）→ 沉台开在**腔侧**

### 9.2 异型孔向导（Hole Wizard）

| 向导要什么 | 选什么 |
|---|---|
| 机丝 + 要藏头 | **沉头孔 Countersink**（GB/T 68 对应） |
| 机丝 + 手上有半沉头 | **半沉头（GB/T 69）**，自定义 |
| 只想要光孔、不要螺纹线 | **套合 = 松弛**，别选「螺纹孔 Tap」 |
| 给螺母的安装孔 | **直孔 Straight**（不是螺纹孔！） |

**四条操作铁律（本项目踩过的）：**
1. **向导把沉台开在「放置面」那一侧** → 想让沉台在腔内，就必须**从腔侧选放置面**。从正面放 = 沉台开到正面，被外盖压住，装配才发现。
2. **改了规格（M3→M2），自定义框会重置** —— 每次都要回头把孔直径手打回 3.00 之类的值。
3. **孔终止条件按用途选**：给螺丝杆的 → **完全贯穿**；给螺母的 → **给定深度**（贯穿了螺母压进去就是个环，白打）。
4. **装配体里没有异型孔向导** —— 要么进零件里做（配合会带外部参考），要么手动两步切除 + 断外部参考。

## 12. 压螺母前后各 5 分钟自检

| 时机 | 动作 | 合格标准 |
|---|---|---|
| 压前 | 卡尺量螺母**外径** | M3×5×4.5 → 4.5 ± 0.2 |
| 压前 | 试拧一颗螺丝进螺母 | 自由旋入 2~3 圈不打滑（确认螺距一致） |
| 压前 | 量孔深 | = 螺母长 + 0.5（M3 → 5.5，底留 0.5 实料） |
| 压后 | 看端面 | 与孔口齐平、背面不凸 |
| 压后 | 试拧到底 | 螺丝能**完全沉进沉台**、头面与面齐平或略低 |
| 压后 | 手扭 | 不转（过盈够） |

**任何一条不过 → 填平往里挪 1mm 重打，别凑合压。热熔螺母歪一个，那一处就永远歪。**

## 13. 一句话沉淀

> **看得见的面 → 沉头 + 沉台 + 热熔螺母（正面藏头）**
> **看不见的面 → 内六角柱头，别折腾沉台**
> **薄壁（<2.5）→ 用 M2，别硬塞 M3**
> **长度永远先算再买，别拿手上的凑**
