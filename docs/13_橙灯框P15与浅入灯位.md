# 13 · 橙灯框 P15：把灯「浅入」到橙色头部上

> 起因：2026-10-02 晚，用户提出「我做鸭子的橙色头部的部分，然后头上面的面往里面浅入一点点，用于放置灯片，好吗」。
> 这是灯光方案的 **v4**，相比 v1~v3 最大的不同：**灯从腔内搬到了脸外表面**。

---

## 0. 先说结论

| 问 | 答 |
|---|---|
| 这个思路行不行 | **行，而且是目前所有方案里最顺的一个** |
| 你比我先想到的那一点 | ✅ **坑不能挖在 P1 前脸上** —— 脸只有 2.5mm 厚，挖 4mm 就打穿、直通声学腔（喇叭漏气，低频全丢）。坑必须挖在**橙件**上 |
| 卡在哪一个数 | **橙外罩 68 宽 < 灯板 78 宽**。一块橙件想同时罩住「眼（Ø48，中心 Y=+16）」和「灯（78 宽）」，必须做到 84 宽 × 101 高 ≈ 整张脸都是橙 → 配色崩 |
| 解法 | **橙件拆成两块**：P14（眼区 68×68，已有不动）+ **P15 橙灯框（灯区 84×30×4，新件）** |
| 「浅入一点点」是多少 | **1.2mm**。板厚 2.8 搁在 4mm 深的窗里 → 灯板正面比橙框外表面**低 1.2mm**，四周被 4mm 高的橙边围住 |
| 还差最后一刀 | 窗不能开到 78×33（那会把整块黑 PCB 亮在脸上）。**窗收到 78×16**，上下各留 4 / 10mm 橙实体挡住灯的上下两端 |
| 代价 | 脸下部 30mm 被橙框占满 → **P4 喙仍然要让位**（见 §6） |

---

## 1. 为什么「坑挖在橙件上」是对的（这条其实是你先想到的）

P1 前脸厚度 **2.5mm**（`11` §2.5 里的脸外表面到内腔底）。

| 想在脸上挖的坑深 | 结果 |
|---|---|
| 3.0mm | 打穿脸 → 声学腔直通大气 → 喇叭漏气、低频丢、可能啸叫 |
| 2.0mm | 勉强剩 0.5mm 实料，太险 |
| **0（不挖脸）** ✅ | 橙框自己 4mm 厚，正面开穿成窗，窗后**就是 P1 的脸面** —— 灯板贴在这片脸面上，**脸一块料都不用挖，通气风险为零** |

而且附带一个好处：**灯板贴脸外表面 = 从前往后装**，不用从后口伸进腔内摸黑拧螺丝（v3 方案里最难受的一步没有了）。

## 2. 新零件 P15 · 橙灯框（尺寸表）

原点：**框心**（相对眼心 Y = −34.5，即绝对 Y = −51 ~ −21 的中点）。
Z=0 贴在 P1 脸外表面，朝外 +Z。

| 项 | 值 | 依据 |
|---|---|---|
| 外形 | **84（X） × 30（Y） × 4（Z）** | X：脸 96，两边各留 6；Y：框顶 −21（橙外罩底 −18 下留 3mm 奶油分型线）、框底 −51（脸底） |
| 圆角 | 四边 **R1.5** | 与 P14 的 R5 呼应，别做成尖角 |
| **正面窗（贯穿）** | **78（X） × 16（Y）**，通框全厚 | 78 = 灯板宽（灯板塞满窗，两端不漏黑 ← §12 §7 那个问题顺手解决）；16 = `11` §8 的 **D 档** |
| 窗绝对位置 | **Y −25 ~ −41**（中心 **−33**） | 对准灯板第 2/3 行灯珠中心跨度中点 −32.9 |
| 框上边（窗上沿到框顶） | 4mm | −21 ~ −25 |
| 框下边（窗下沿到框底） | 10mm | −41 ~ −51 |
| 材质 | PETG，橙 **#F26B21** | 与 P14 同批漆 |
| 数量 | 1 | |

### 2.1 灯板摆位

| 项 | 值 |
|---|---|
| 灯板 | 78（X） × 39（Y） × 2.8，2 块并排 |
| 贴哪 | **P1 脸外表面（z=0 平面），LED 面朝 +Z（朝外）** |
| 板心 **Y = −31** | 板 −50.5 ~ −11.5；板底距脸底 −51 留 **0.5mm**（卡死）；板顶 −11.5 藏在橙外罩后面（外罩底 −18）✓ |
| 可见部分 | 只在窗 **−25 ~ −41** 这段露出来（16 高） |
| 被遮部分 | 板 −50.5~−41 和 −25~−11.5 两段被 P15 橙实体挡住 → **PCB 底板、四周焊盘、排针全部看不见** ✓ |
| **浅入量** | 窗深 4 − 板厚 2.8 = **灯板正面比橙框外表面低 1.2mm** ← 这就是「往里面浅入一点点」 |

### 2.2 为什么窗必须是 16 而不是 33

| 窗高 | 结果 |
|---|---|
| **33**（全露） | 78×33 的黑 PCB 整片亮在脸上下部 —— 完成度红线明写「不是『贴上去』」。出来是「一块小屏幕」 |
| **16** ✅ | 只露中间 2 行灯珠（中心 −36.8 / −29，跨度 7.8 ⊂ [−41,−25]）；上下各 4 / 10mm 橙实体挡住 PCB。正面读出来是「**一条发光的横槽**」 |
| 12 | 更保险，但 2 行灯珠（Ø5）在 12 高里只剩 3.5mm 缝，光糊成一条线，点阵感消失 |

**16 是「看得出是灯、又不像贴了块屏」的最大值。** 再往上就踩 §2.5 那个扩散悖论（`11` 文档）。

## 3. 固定：不用螺丝，用 3M VHB + 2 颗定位柱

跟灯板一个判据（§12 §2）：**薄件在脸上是不受力的，它被「贴」进去，不是被「锁」进去。**

| 项 | 做法 |
|---|---|
| 主固定 | P15 背面（贴脸那面）整面贴 **3M VHB 4910 / 505**，压在 P1 脸外表面 |
| 定位 | 框上沿 2 颗 **Ø3 圆销**朝腔侧伸出 4，插进 P15 上边实体里的 2 个 Ø3.2 孔 → 定上下位置 |
| 返修 | 热风枪 80℃ 可撕，或撬开（橙框不是受力件） |
| 为什么不用 4 颗 M2 | 框高只有 30、窗 16 → 上边实体仅 4mm 高，**放不下 Ø4.0 沉头 + Ø3.0 孔** |

> 如果 VHB 不放心：退路是 **2 颗 M2×10 从腔内拧**，位置取框左右两端（X ±38、Y −24 与 −47），
> 长度复核：沉头 1.2 + 穿脸 2.5 + 咬合螺母 3.0 = 6.7 → **M2×10 富余 3.3** ✓。但优先走胶体。

## 4. SolidWorks 建模步骤（P15）

1. 新建零件 **P15 · 橙灯框**，原点 = 框心（绝对 Y = −34.5），Z=0 为贴脸面
2. **凸台-拉伸**：前视基准面 → 84 × 30（相对原点智能尺寸）→ 拉伸深度 **4**，方向朝 +Z（朝外）
3. 四边 **倒角 R1.5**
4. **切除-拉伸（通）**：同一基准面（或正面）画 78 × 16 矩形，
   - X 相对原点 ±39，
   - Y 距框**上边 4**、距框**下边 10**（这两个数直接标智能尺寸，别标窗心，避免后面算反）
   - **终止条件：完全贯穿**（这口就是要穿透 4mm 的框，露出后面的脸面）
5. 自检 Ctrl+8：**窗是通的（能看到后面的东西）、框四周是实体、板面在窗里低 1.2**
6. 保存，进装配体，Z=0 面与 P1 脸外表面 **重合配合**

### 4.1 进 SW 前先确认两件事

- **P1 脸外表面在 78×39 这块区域（Y −50.5 ~ −11.5）必须是平的。** 腔内的横杆 / 四片三角板 / 加强筋如果顶到脸背面，灯板贴不实。先转腔侧看一眼那块区域。
- **灯板导线怎么出。** 灯板贴在脸**外**面，线要回到 ESP32（在身部），只能：
  灯板背面 → 沿脸面下沿（−50.5 到 −51 那 0.5mm 缝）→ 绕过脸下沿进腔 → 走颈 P7 下到身部。
  **DIN 必须软硅胶线**（24AWG 镀锡线太硬会顶着脸面和橙框）。

## 5. 装配顺序（改了一步）

1. ✅ 已完成：台面点亮测试（`12` §5，今晚就能做）
2. P1 脸外表面那块区域清理平整
3. **先在脸面上贴灯板**（胶体）+ 2 颗定位柱定灯位
4. 从灯板底沿引线进腔、理线（此时腔是敞开的，好走线）
5. **再扣 P15 橙灯框** —— 顺序不能反：先灯后框，框压住灯的上下两端
6. 橙外罩 P14 照旧压在上边（Ø48 圈 + Ø52 沉台，护住方兰）
7. 腔内装电路、穿线 → 从后口伸进腔内拧合壳 M3×10（P1↔P2）→ 合 P2

## 6. 代价：P4 喙仍然要让位（v3 的结论不变，但让位方式变了）

橙灯框占掉脸下部 **−21 ~ −51** 共 30mm，而：

- P4 喙面板 = 100 宽 × **29 高**，若贴脸下部 → 顶在 −22 左右，正好压在窗（−25~−41）上 → **喙会把灯遮掉**
- 窗是发光的，喙是凸出的实体 —— 两者在正脸重叠，必须砍一个

三个退路（按推荐排序）：

| 退路 | 做法 | 代价 |
|---|---|---|
| **① 合二为一** ⭐ | 取消独立喙 P4，把「喙」做成 P15 橙框**往下伸出的那 10mm 边 + 前伸 3~4mm** —— 橙框自己就是喙的「根」，保持前伸下倾的语汇 | 喙变矮（≤14 高），形态语言削掉一半 |
| ② 喙压到最下沿 | 喙 14 高，Y −37 ~ −51，前伸 10 | 喙几乎只剩一条边 |
| ③ 取消喙 | 正脸 = 橙顶盖 / 橙眼框 / 橙光槽，三段横向分区（MicroDuck 的几何分件语言） | 六条设计语言里「喙的语言」没了 |

**我的建议是 ①**：橙框下沿前伸 3~4mm = 一条有厚度的橙色压条，既保住「橙色」这个色的落点，又不用一个新零件。

## 7. 这条路相对 v3 省了什么 / 多了什么

| | v3（灯在腔内 + 光口 32） | **v4（本方案）** |
|---|---|---|
| 净空约束 | 30.5mm（外罩底 → 内腔底） | **无约束**（灯贴脸外表面，脸 96×102 随便放） |
| 挖脸 | 不用挖 | 不用挖（框开穿，脸一块料不动） ✓ 不漏气 |
| 灯板装配 | 从后口伸进腔内、贴内腔底摆死 | **从前往后贴**，看得见摸得着 ✓ |
| 走线 | 腔内穿线 | 脸下沿绕进腔，仍要过颈 → 差不多 |
| 固定 | 定位销 + 胶体（腔内黑） | 胶体（脸外，好操作）✓ |
| 新零件 | 0 | **+1（P15）** |
| 灯板摆位自由度 | 被 30.5 卡死，只能贴底摆死 | 自由（本方案定 Y=−31） |
| 喙 | 必须砍 | 仍要砍，但可以「橙框下沿前伸」救回一点 |

**净结论：省掉的是「腔内黑摸装配」和「净空 30.5 的死约束」，代价是 +1 个零件。这笔账划算。**
