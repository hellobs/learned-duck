## 1. 拓扑：先想清楚一件事 —— ESP32 管音频吗？

这是整个电路**唯一需要先拍板**的架构问题，而且它现在在文档里有歧义。

| | 蓝牙功放板 | ESP32-C3 |
|---|---|---|
| 会不会自己收蓝牙 | **会**（清单写的"蓝牙功放板"） | 也会（但你不打算用） |
| 拉到手上的角色 | **音频链路的实际承担者** | 只管灯和按键 |

**清单里那块是「蓝牙功放板，10W/15W/20W 立体声，12V 输入」—— 它自带蓝牙接收器。**
也就是说：手机 → 功放板（板自己连蓝牙）→ 功放 → 喇叭，这条链路**根本不经过 ESP32**。
ESP32-C3 的价值只在于 **WS2812 灯 + 按键**。

### 1.1 两条路，差别很大

| | 方案 A：**功放自制蓝牙**（推荐，最省事） | 方案 B：ESP32 当音频源 |
|---|---|---|
| 链路 | 手机 ⇄ 功放板 → 喇叭 | 手机 ⇄ ESP32 →（A2DP/I2S）→ 功放 → 喇叭 |
| 代码量 | 灯：一个 NeoPixel 循环 | 灯 + 蓝牙 A2DP + I2S + 缓冲管理（几天量级） |
| 风险 | 低 | **高**：ESP32-C3 的 A2DP 在 Arduino 下不稳，缓冲抖动会爆音 |
| 副作用 | ⚠️ 手机会看到**两个蓝牙设备** | 只有一个 |
| 讲评 | 课程是建模课，别把硬件课的量加进来 | 见 `MEMORY.md`「课程定位修正」 |

**推荐 A。** 你这门课是建模课，电路是"让它亮、让它响"的及格线，不是主战场。

### 1.2 ⚠️ 方案 A 必付的代价：两个蓝牙

手机搜索蓝牙会同时出现：
- 功放板广播的（名字常是 `XY-xxxx` / `BT-……`，看板子贴纸）
- ESP32-C3 的（烧了固件后你自己在代码里 `ESP.restart()` 前的默认名，或 `WiFiSoftAP` 之类）

**后果**：每次开机，用户要在这两个里挑对的那个连。老师/同学拿起来试，极可能连到 ESP32 上，发现"连上了没声音"，直接判失败。

**三条处理，按性价比排：**

1. **不烧 ESP32 的蓝牙**（默认就没烧）→ 它开例程之前就是个裸板，不会出现在蓝牙列表。**最省事，几乎零成本。**（默认 ESP32-C3 不烧任何程序时确实不广播，这也是推荐 A 的又一条理由）
2. 烧固件时把 ESP32 名字起成 `LD-LAMP`（明确不是音箱），并在 README 写一句。
3. 别去改功放板名字（要看板子有没有 AT 指令口）。

> **先确认一件事再往下做：你手上那块蓝牙功放板有没有 AUX（3.5mm）输入口？**
> 有 → 方案 A 稳；只有 BT 一种输入 → 也一样能走方案 A（本来就不需要它转接给 ESP），
> 但你要知道"信号从哪进" —— 若它只有 BT，那 ESP32 与功放之间**没有任何信号线**，只有 GND 关系（§4.3）。

## 2. 电源树与电流预算（重算）

### 2.1 树形

```
12V 适配器（自备 / 待购）
  └─→ DC022 电源座（开孔 Ø12，装在身部下沿，靠下 = 力臂最短）
        └─→ 拨动开关 SS12F15V（★ 装在 12V 总线最前端，切断总电源）
              ├─【支路 1 · 直通 12V】→ 蓝牙功放板 → 1× 喇叭（4Ω 10W，**单声道**）
              └─【支路 2 · 经降压】→ DC-DC 降压模块（12V → 5V，持续 1.6A）
                                      ├─→ ESP32-C3（5V，~0.1A）
                                      └─→ WS2812 灯板（5V，见下表）
金属按钮（Ø10，面板）→ ESP32 GPIO → 灯模式 / 开机自检
```

**开关的位置是关键**：拨动开关串在**进入全机的 12V 总线最前端**，不是串在灯支路。
关机 = 全机断电（功放也停），不是"只关灯"。这也符合"拨动开关是电源总开关"的常见直觉。

### 2.2 电流（按头顶方案「只点中间一行 10 颗」算，这是新的账）

| 支路 | 典型 | 峰值 | 说明 |
|---|---|---|---|
| **功放 + 喇叭（12V 侧）** | 0.3–0.8 A | **≈ 2.0 A** | 20W 输出 / 12V / 效率 ~85% → 24W 输入 ≈ 2A |
| 降压输入（12V 侧） | 0.15 A | 0.3 A | 输出 ~0.5W ÷ 效率 0.9 ÷ 12V |
| ESP32-C3 常态 | 0.1 A | 0.2 A | Wi-Fi 瞬时更高 |
| 灯 10 颗（头顶方案） | 0.28 A | 0.6 A | 单颗 WS2812B 满白 60mA；亮度 120/255 ≈ 47% |

**合计 12V 侧 ≈ 2.3 A（峰值）→ 适配器 12V/3A 起步（2A 太紧，别赌）。**

### 2.3 一个好消息：亮度上限那条铁律，头顶方案下解除了

`02`/`12` 定「亮度 ≤120/255」，是因为原来要带 50 颗甚至 75 颗。
**头顶只点 1 行 = 10 颗 → 0.28A @120/255。**

| 亮度 | 10 颗电流 | 降压总负载（含 ESP） | 对 1.6A 余量 |
|---|---|---|---|
| 120/255 | 0.28 A | 0.38 A | **4.2 倍余量** |
| 180/255 | 0.42 A | 0.52 A | 3.1 倍 |
| 255（满） | 0.60 A | 0.70 A | 2.3 倍 |

**结论：头顶单行方案下，你可以放心把亮度上限放宽到 180/255**（曲线更好看、更"发光"），
1.6A 的持续限仍有 3 倍余量。
> 除非你哪天又让 50 颗全亮 —— 那必须回到 120/255。

### 2.4 两个不能碰的电源规矩

1. **功放吃 12V 直供，不经过降压。** 降压只喂数字侧（ESP + 灯）。反过来（灯从 12V 直取再降）会有纹波串进音频。
2. **灯板 5V 从降压模块「单独引一路」**（用 2 根线直接连降压的两个输出邮票孔），**不要和 ESP32 共用一条 24AWG 跳线** —— 长距离共用会把数字开关噪声带进 ESP 的供电。

## 3. 走线路径（头顶方案的真正代价）

### 3.1 三条线，两个方向

| 线 | 起点 → 终点 | 经过 |
|---|---|---|
| **① 喇叭线**（2 芯） | 功放（身） → 喇叭（头正脸） | 身 → 颈 → 头内 → 前脸背面 |
| **② 灯线**（3 芯：5V/GND/DIN） | 顶盖灯盘（头顶） → ESP32（身） | 顶盘壁槽 → 头内 → 颈 → 身 |
| **③ 电源/控制**（可选） | DC 座 + 开关 + 按钮（身） | 全在身，不走头 |

**关键时间窗：头壳（P1↔P2）一旦合上，① 和 ② 就必须已经接好、并塞到位 —— 之后手伸不进去了。**
所以「穿线」这一步必须在**合 P2 之前**完成（跟之前定的装配顺序一致）。

### 3.2 ⚠️ 颈 P7 里的空间账（这是本次新算出来的，之前没人算）

灯跑到头顶之后，**颈里同时要过 ① 喇叭线（2 芯）和 ② 灯线（3 芯）= 5 芯线**，
外加结构上的 **2 根 M4 螺纹杆**。

```
颈内径 D。2 根 M4（Ø4）贴内壁走：
  中间净宽 = D − 8        （两根杆各占一侧 4mm）
判据：净宽 ≥ 12  →  D ≥ 20
```

| 颈内径 | 中间净宽 | 结论 |
|---|---|---|
| ≥ 22 | ≥ 14 | ✓ 宽裕 |
| **20** | **12** | ✓ 刚好够（这就是「≥12mm 净宽」这条老规矩的来源） |
| < 20 | < 12 | ❌ 要改：单根 M4 居中（占 4）+ 一侧走线，或颈内径放大 |

**进 SW 建 P7 之前先量：颈的内径是多少。** 若算出来 < 20，只有两条路：
- M4 从 2 根减到 1 根（脊柱够不够强度另说，颈是压柱不是拉柱，1 根居中其实可行）；
- 颈内径从原设计放大 2mm（颈是外露视觉件，放大 2mm 会改视觉比例 —— 这是造型账，得你拍）。

> 顺带：这 5 芯里 **①喇叭线是模拟音频、②灯线是高速数字**，
> **不能贴着并排走同一侧**（DIN 的方波会在喇叭线上感生底噪）。
> 走法：**灯线走颈的一侧、喇叭线走另一侧**（正好和两根 M4 各占一边对齐），
> 到头内/身内再分别拐向自己的目标。

### 3.3 过线孔（三处，每处都要硅胶封）

1. **顶盖托盘侧壁 Ø10 过线槽**（灯线出盘）—— 若盘壁还没开，现在开还来得及（P3 还没打）。
2. **头底 → 颈 的 Ø12 孔**（① ② 都从这里下到颈）—— 别撞 DC 座那个孔（DC 座在身部下沿）。
3. **颈 → 身**（在同一区域，用线卡固定在颈内壁，别让它晃）。

> 声学腔唯一的开口仍是 P1 上那个 **Ø10 过线孔**（喇叭线从功放进前脸背面用的），
> 必须硅胶封死 —— 这是 `05` 的老规矩，别把它和上面三处混。

## 4. 接线表（照着焊）

### 4.1 12V 侧

| # | 从 | 到 | 规格 | 备注 |
|---|---|---|---|---|
| 1 | DC022 中心针（+） | 拨动开关 脚 1 | 20AWG 硅胶，短 | ⚠️ 见 §4.4 线径 |
| 2 | 拨动开关 脚 2 | 功放板 12V+ | 20AWG，走身底 | 直通 |
| 3 | 拨动开关 脚 2 | 降压模块 IN+ | 20AWG，短 | 与 2 同点分叉 |
| 4 | DC022 外壳（−） | 功放板 12V− / 降压 IN− / 开关 脚3 | 20AWG | 三处**同一个地** |
| 5 | 功放板 OUT L | 喇叭（成品里唯一的那一只） | 24AWG 可，≥20AWG 更好 | 走颈 |
| 6 | 功放板 OUT R | **不接（悬空）** | — | ⚠️ **只接一路。两路并到同一只喇叭 = 4Ω∥4Ω = 2Ω，功放会过流保护甚至烧** |
| 7 | 拨动开关 脚 3 | （悬空 / 或不接） | — | 拨动只当单刀单掷用 |

> **DC022 是「中心正、外壳负」**（常见）；极少是中心负。**插之前拿万用表量一下**，
> 接反了功放会烧（有保护的好一些，没有的直接废）。

### 4.2 5V / 数字侧

| # | 从 | 到 | 规格 | 备注 |
|---|---|---|---|---|
| 8 | 降压 5V+（邮票孔） | 灯板 VCC | 24AWG 软硅胶，**单独一路** | 见 §2.4 |
| 9 | 降压 5V+ | ESP32 5V | 24AWG | 同上分叉点 |
| 10 | 降压 GND | 灯板 GND | 24AWG | |
| 11 | 降压 GND | ESP32 GND | 24AWG | **与 8/9 同一个地** |
| 12 | ESP32 **GPIO4** | 灯板 DIN | **软硅胶 22AWG + 串 330Ω** | 焊在 DIN 焊盘外 5~10mm |
| 13 | ESP32 GPIO（按钮） | 金属按钮 一脚 | 软线 | |
| 14 | 按钮 另一脚 | ESP32 GND | 软线 | 按钮另一端接 GND = 按下拉低 |

**GPIO 选哪个：用 GPIO4。** 别用 0/2/3/9/10（上电 strapping 脚）、1/3（UART0）。

### 4.3 关于"共地"到底共哪一处

| 网络 | 接法 |
|---|---|
| 12V 地（电源负极） | DC022 外壳 → 功放 −、降压 IN−、开关脚3，全是一点 |
| 5V 地（数字地） | 降压 OUT− → ESP32 GND、灯板 GND，全是一点 |
| **两地的连接** | **降压模块的 IN− 与 OUT− 本身在模块内部就是连通的**（DC-DC 是共地拓扑）→ 所以两个地**自动是一点**，不用你额外连 ✅ |

⚠️ 但你**必须确认降压模块是「非隔离」DC-DC**（你这块就是，双邮票孔 mini 降压都是非隔离）。
如果是隔离型（很少见），IN− 和 OUT− 不连，那时 5V 地的回路要靠别处走，会出问题。

### 4.4 ⚠️ 线径：24AWG 用在 12V 主线上太细

清单里只有 **24AWG 镀锡跳线（1007 双头）**，载流大约 2A 上限（ chassis wiring 级），
而 12V 峰值要 **2.0A**、且路径里有 DC 座 → 开关 → 功放的接头。24AWG 会**发热 + 压降**。

**采购一行：20AWG 硅胶线（红/黑各 1 米）+ 热缩管。** 只用在 #1~#4 这 4 根（12V 总线）。
其余（5/8~14）24AWG 完全够。

## 6. 装配顺序（电路部分）

```
① 台面测试 1（今晚就能做，不依赖任何壳件）
   功放板 + 12V 电源 + **1 只喇叭**接线 → 通电听声（蓝牙连上、有声音 = 音频链路通）
   ⚠️ 单声道：功放只接 OUT L，OUT R 悬空。别两路并到一只喇叭（变 2Ω，过流）
② 台面测试 2（灯）
   降压 12→5 + ESP32 + 两块灯板（先分开测单颗 → 再串联）→ 烧亮度 180/255 看 10 颗亮 = 灯通
③ 身部装配：钢板 → 功放 → 降压 → ESP32 → DC 座 → 开关 → 按钮 → 理线
④ 合身上盖（此时电路全在身里）
⑤ 穿颈线：① 喇叭线、② 灯线 各从颈的一侧放下去（灯线一侧 / 喇叭线一侧，别并排）
⑥ 头内装灯板（先）→ 扣顶盖托盘（框压灯）→ 前脸装喇叭（4 颗 M3 从正面拧）
   → 橙外罩压上 → 腔内拧 4 颗 → 过线孔硅胶封
⑦ 合 P2 后盖（合上就再也伸不进手了）
⑧ 全机通电：蓝牙连功放（不是连 ESP）→ 声音 → 灯随音乐 → 按钮切模式
```

> **① ② 绝不能跳。** 装进壳再发现灯不亮/没声音，要拆整只头。

## 7. 七个坑（按会让你返工的程度排）

1. **⚠️ 颈内径 < 20 → 5 芯线 + 2 根 M4 塞不下**（§3.2）。建 P7 前先量，这是硬约束。
2. **⚠️ 蓝牙有两个设备**（§1.2）。默认不烧 ESP 蓝牙最省事。
3. **⚠️ 灯线和喇叭线在颈里要分两侧走**（DIN 方波感生底噪）。
4. **DC022 极性**：中心正还是中心负，接之前量。
5. **24AWG 上 12V 主线**（§4.4）：买 20AWG。
6. **ESP32 天线 10mm 净空**：贴死壳壁 = 蓝牙直接废，这是最容易在装配最后才发现的问题。
7. **功放散热**：20W 封在 0.20L 塑料腔里，钢板 + 导热硅胶垫是唯一可靠出路；别指望自然对流够。
