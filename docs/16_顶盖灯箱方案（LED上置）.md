## 1. 先判一件：头顶放得下吗（尺寸核算）

| 项 | 值 | 判断 |
|---|---|---|
| 头顶可用面 | **96 (X) × 62 (Z)** | 头 96W × 102H × 62D，顶面就是这么大 |
| 两块灯板（含拼缝） | **80 (X) × 40 (Z)** | 39×39 两块并排 |
| 托盘内腔 | 需 ≥ 84 × 44（壁 2） | |
| 托盘外廓 | **92 × 52**（壁 5，墙高 10） | |
| **顶面对托盘的余量** | X 方向 **2mm/边**、Z 方向 **5mm/边** | ⚠️ 贴到边了，**四角 R 必须收，不能做方正大 R** |
| 灯板离盘口 | **约 13**（墙高 10 + 盘底 2.5，灯珠面在盘底之上 3） | 墙够高 → 侧向漏光被挡 ✓ |

**结论：装得下，但只剩 2mm 边距 —— 托盘必须是「顶盖 + 浅盘」的一体件，不能做成悬挑的独立大框。**

> 这条顺带解释了为什么托盘看起来比壳宽：外廓 92 对顶面 96，两边各 2mm，视觉上几乎是齐平的。**这不是误差，是算出来的。**

## 2. 造型判断（本节是真建议，不是尺寸）

把灯从"前脸光缝"搬到"头顶托盘"，**扩散悖论不会消失，只是换了个地方**：

| | 前脸（P15 方案） | 头顶（本方案） |
|---|---|---|
| 正/俯视看过去 | 见到一条 **16mm 高的横带** | 见到 **10 列 × 5 行的亮点阵列** |
| 单个读感 | 光带 | **像散热片 / 通风口 / 排插指示灯** |
| 加扩散板 | 5 行糊成光斑，脸没了 | 整个盘口一块柔光 → 变成"发光铭牌" |
| 与那只眼关系 | 一眼在上、光带在下，不抢 | **头顶 + 正脸两个发光体**，头部重心被拆成两半 |

**头顶是仅次于正脸的第二注意力区。** 你在头顶放 50 颗独立的方灯珠，正脸又有一只眼 —— 一件东西上两个"发光体 + 一个"眼"，比只有一个更散。MicroDuck 的头顶是干净的橙色顶盖，它的光语是"眼睛 + 底座"，不是"头顶一片"。

### 但这条方案有一个真优势，别忽视

托盘的**四壁本身就是遮光框**（墙高 10 > 灯珠离盘底 3，侧向光被吃掉大半）。
也就是说：**头顶方案天生自带光箱腔体，前脸方案还得单独挖光腔。** 这是它唯一比 P15 省事的地方。

## 3. 如果要做下去，三个必须补的机械点

### 3.1 盘底 2.5 太薄 —— 塞不进 M3×5×4.5 热熔螺母

热熔螺母要 **≥4.5 深**的孔才咬得住；盘底 2.5 压进去会凸到盘底外面、还会把盘底顶穿。

**两条路：**

| | 做法 | 评价 |
|---|---|---|
| **A（推荐）** | 盘底做 **4 个 Ø6 凸台、高 4.5**，台顶埋 `M3×5×4.5`（孔 Ø4.3 × 深 5.5，底留 0.5 实料） | 与全项目 `14` §5 同一套算法，打印稳定 |
| B | 盘底**不加厚到 5**，用 **自攻螺母 / T 型螺母** | 省事，但你没买，且 2.5 薄板上自攻螺母容易滑 |

**别用 VHB 直接贴**：灯板会受轴向振动（喇叭在下面振），胶会慢慢脱。托盘这个位置是**悬在声学腔正上方**的，振动比脸面大。

### 3.2 螺丝从哪面拧 —— 头顶要"从下往上拧"

灯板四角孔是 **M3 沉孔**（实物照见 `12` §0）。螺丝头沉进板的沉孔 → **板顶面齐平、头顶看不到一颗螺丝头** ✓（这条本来就成立）。

但要进到底下的凸台，螺丝只能**从盘底往上穿**（从盘口往下拧的话，头就压在板正面了 —— 等于头顶顶着 4 颗黑十字）。

| 项 | 值 |
|---|---|
| 长度核算 | 螺丝头沉台 1.65（在板内）+ 板厚 2.8 + 咬合凸台里螺母 2.0 = **6.45** |
| 建议 | **M3×10 沉头**（杆长富余 3.5，且 `15` §4.2 有冗余） |
| **别用** | M3×8（杆 7.35，富余 0.9，太险） |

> 顺带：这跟前脸那套 `M2×10` 是**反过来**的 —— 前脸"从腔内往里拧"，头顶"从盘底往外穿"。头壳上现在有 M2 和 M3 两个方向的螺丝，别混。

### 3.3 出线：头顶的灯要走了头顶 → 头内 → 脖子 → 身，三段

这是头顶方案**最大的代价** —— 灯不在脸上了，线就得从头顶绕一大圈：

```
盘壁开 Ø10 过线槽  →  头内（声学腔上方）  →  头底颈接口  →  颈 P7 内  →  身腔
```

三处过线孔**每一处都要硅胶封**（`10` §10.2b 的老规矩）：
1. 托盘侧壁的过线槽；
2. 头底通往颈的 Ø12 孔（DC 座那个孔已经占用下沿，别撞）；
3. 颈 P7 里那 2 根 M4 螺纹杆之间 —— **两根 M4 之间要留 ≥12mm 净宽**给线束，否则出不去。

> ⚠️ 头顶走线**穿过声学腔上方**。喇叭振膜在正面、腔体在 P1 碗里，线束只要不贴着前脸走、`不在振膜正后方摆`,就不会影响声学。但**线卡要固定在盘底或顶壁，不要悬在腔中间晃**。

## 4. 固件：头顶方案下，只点一行（这条是本方案的关键补丁）

50 颗全亮 = 头顶 10×5 亮点阵列 = 散热片。

**只点亮中间那一行（10 颗）→ 阵列退化成一条线 → 直接自证为"光带"。**

| 项 | 值 |
|---|---|
| 点亮的 | 第 3 行（10 颗），其余 4 行全灭 |
| 读出来 | 头顶一条**贯穿前后**的光棱，长 80、灯距 8 |
| 电流 | 10 颗 ≈ **0.6 A**（远低于 `03` 定的 1.6A 持续 / 亮度上限 120/255 的约束） |
| 动效 | 仍是训练曲线（10 段柱高随音乐起伏），开机从左→右扫一次 |

**这跟前脸 P15 的"训练曲线"是同一个主语，只是换了位置。** 主题没变 —— 一条 curve，不是一张脸。

## 6. 这张图里两件必须查的事

### 6.1 装配树里有 30+ 颗 "cross recessed countersunk head"

我们全项目规划的螺丝总量是 **12 颗左右**（喇叭法兰 4 + 橙外罩 4 + 合壳 4 + 髋腿若干），**这里一下冒出 30+**。

请点开任意一颗看它的**配合/钉入面**，分辨三类：
1. 落在 **P1 凸台顶** = 锁喇叭法兰（正常，本来就该从正面拧，靠遮罩盖住）；
2. 落在 **P14 遮罩** = 从前打螺丝 → **与前盖的意义直接冲突**，要改成腔内拧；
3. 落在 **P3 顶盖 / 灯板** = 头顶这批，按 §3.2 重算。

> 数量对不上本身不是罪（可能只是把块显示成了多实例），但**每一颗都得有名字**，装配树里 30 个同名 `cross recessed countersunk head` 是以后做 BOM 和采购的灾难。

### 6.2 头顶托盘有没有开过线孔

盘壁上**必须有一个 Ø10 过线槽**（§3.3）。如果现在盘壁是封死的 —— 灯板线只能走盘外、绕到壳外，那就是"外部看得见线"，直接踩完成度红线。

## 7. 我的建议（一句话）

**头顶方案能做，但要做成「只点中间一行」的 10 颗光棱 —— 不要 50 颗全亮。**

理由不是省电，是**50 颗点阵 = 散热片，10 颗一条线 = 光带**。二者在头顶这个位置差别是"廉价电子件"和"设计语言"的差别。

如果按这条走，`13` 的 P15 橙灯框**就不用建了**，前脸回到「橙顶盖 / 橙眼罩 / 奶油脸」三块——干净，喙（P4）可以按原样保留，**不用为灯让位**。这反过来补回了一个我们为了灯差点砍掉的东西。
