# 智能蓝牙音箱 · 零部件测绘表

> 对应作业要求第 1 条：**通过测量零部件尺寸，确定零部件在内部的堆叠方式**。
> 这张表是后面所有造型、结构、开孔的**唯一数据源**。数字错 1mm，外壳就可能装不进去。
>
> 测量工具：游标卡尺（不用卷尺、不用目测）
> 记录精度：**0.1mm**（开孔类尺寸也顺势记到 0.1mm）
> 填写方式：直接在本文件「实测」列填数字，或在纸上记完回填。

## 二、3D 打印设计约束速查（建模时直接套用）

| 项目 | 规则 |
|---|---|
| 最小壁厚 | 1.6mm；承力柱/螺母柱 2.0mm |
| 热熔螺母柱外径 | M3 螺母 → 柱外径 ≥ **Ø7.0mm**；M2 螺母 → 柱外径 ≥ **Ø5.5mm**（两侧壁厚各 ≥1.2mm） |
| 螺母压入孔 | 比螺母外径小 0.2~0.4mm（M3 → Ø4.1；M2 → Ø2.7），**以实测螺母外径为准** |
| 螺丝通孔 | M3 → Ø3.4mm；M2 → Ø2.4mm |
| 沉头窝 | M3 头径 Ø5.6~6，锥角 90°，深度按实测头高 |
| 打印公差 | ±0.2~0.3mm；所有配合面留 **0.3mm 装配间隙** |
| 螺纹配合 | 3D 打印件不直接攻牙，一律用热熔螺母 |
| 喇叭后腔 | 2 寸全频建议净深 ≥ 15mm；喇叭与壳体接触面加**泡棉/密封胶**，避免漏气 |
| 天线净空 | ESP32 天线端与蓝牙天线侧，10mm 范围内不要金属、不要紧贴壳壁（否则信号衰减） |
| 走线 | 线槽截面 ≥ 5mm；电源线（12V）与信号线分开走，减少干扰 |
| 装配可达性 | 建模时先想一遍**螺丝刀怎么伸进去**——这是新手翻车率最高的一项 |

## 三、拍照归档要求

每件零件拍 **1 张俯视 + 1 张侧视**，能同时看到卡尺读数的更好。命名：

```
零件名_俯视.jpg / 零件名_侧视.jpg
```

放同一文件夹，后面做装配示意图和爆炸图时能直接引用，也方便我帮你核尺寸。

## 四、量完之后

把填好的表发我，我接着做两件事：

1. 核算并给出**箱体最小内腔尺寸**（长 × 宽 × 高）与各件的堆叠排布方案（2D 侧视 + 顶视）
2. 标出所有**必须预留的开孔与净空区**，作为造型设计的硬边界

> 记住顺序：**先量后画**。现在多花两小时测量，能省掉后面重打一整个外壳的时间。
