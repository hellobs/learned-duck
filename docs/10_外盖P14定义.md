# P14 外盖（遮罩）定义 v2 · 2026-10-02

## 0. 依据：实物参考

四张实物照（同学的双喇叭音箱模块）读出的三条：

1. **外罩是独立薄板件**，压在壳体正面最外层，把喇叭的方法兰、四角安装螺丝头全部盖住，只露出圆孔里的振膜。
2. **固定方式 = 外罩自带热熔螺母（四角金色）+ 壳体开通孔 + 螺丝从壳体另一侧（腔内/背面）穿出来往里拧**。正面看不到一颗螺丝头，只看到螺母的金色环。这正是我们已经定的"从后往前"，实物证明可行且是最简做法。
3. **罩的孔口带一道内翻边/浅沉台**（图 4 里喇叭是"坐进"蓝色孔的台阶里，不是贴平的）。这道边让振膜看起来是嵌进去的。

> 我们原来设计的"外盖背面伸 3 根 Ø5 柱 + 前脸开 3 个 Ø6.5 大孔 + 柱端埋螺母"**作废**。
> 柱是悬空特征，打印娇气；Ø6.5 大孔破坏后腔密闭；柱端盲孔里热熔小螺母极易歪斜。
> 改成与实物同构的"薄板压螺母 + 脸部小通孔"。

## 1. 一个之前的判断错误（订正）

外盖贴在脸的**外表面**（Z > 0 一侧），它的 X/Y 范围只受 **脸外轮廓 96 × 102 约束**，
**不受"内腔 Y ±48.5"约束**（外盖不在腔内）。

→ 由此，昨天说的"顶部放不下第 4 个螺丝点"作废（旧判据用错了约束面）。
→ 外盖可以放大到 68 × 68：Y ∈ [−18, +50]，顶边 50 < 头高半边 51，正好到头轮廓顶留 1mm。

## 4. 装配顺序（顺序不能乱）

1. P1 前脸 4 个 Ø3.0×深5.5 盲孔埋 M2 热熔螺母 → 装喇叭，4 颗 M2×8 **从外**拧进法兰凸台（螺丝头被外盖吃掉）
2. 贴 2mm 闭孔泡棉环（Ø48 周围，气封）
3. 腔内侧：装功放板 / ESP32 / 降压模块 / 穿线（过线孔 Ø10 落在 P1 实体上）
4. **外盖热熔螺母（打印后单独工序，装配前做完）**
5. 外盖扣上（背面贴脸，四角螺栓位对准前脸 Ø3.0 孔）
6. **从后口伸进腔内**，拧 4 颗 M2×10 沉头 → 正面零螺丝
7. 4 个孔位点硅胶/热熔胶封（后腔只求密闭）
8. 合后壳 P2（M3×10）—— 注意必须在第 6 步之后，合完手伸不进腔

## 6. 外观判断（外罩改橙之后）

### 6.1 定下来的三件事

- **不做双色**（外圈奶油 / 内环黑）。双色打印或多一道分色工序不值得，边界对不齐反而脏。
  整块橙，靠 **Ø52 浅沉台** 那道 1.2mm 台阶自己分层次——台阶外是橙平面，台阶里是黑振膜，再往里是 Ø48 通道。三级只读得出来。
- **"外圈不喷黑、留奶油"这个备选取消**。整片一块橙，最省事。
- **头顶那条橙会连到眼下，这是几何必然，不是画糊了。**
  外罩顶边 Y=+50、头轮廓顶 Y=+51，中间只剩 1mm；而顶盖就在头顶。
  所以正面上部从 Y≈+50 一路到眼下，是一整块橙（顶盖 + 外罩 视觉上成一块色分区）。
  这是 68×68 的必然结果（盖心锁死在眼心 (0,+16)、必须对称包住方法兰），**不是缺陷** —— MicroDuck 的 orange 也是这样分区的。

### 6.2 唯一要防的：外罩下沿 vs 喙顶

外罩下沿 **Y = −18**。喙面板（P4）在正脸下部，高 29。
→ **判据：喙顶边必须 ≤ −26**，即两者之间要留 **≥8mm 奶油带**。
→ 低于 8mm 就是一条奶油细缝，看着像没对齐的接缝，不像配色。

两条路（核完喙的实际 Y 再选）：

| 路 | 做法 | 代价 |
|---|---|---|
| A（首选） | 保持 68×68。前提是喙顶 ≤ −26 | 需要喙往脸底贴：喙 29 高 → 喙底 = −55？放不下（脸底 −51）。**所以 A 大概率不成立** |
| B | 外罩收到 **58×58**（半边 29，螺孔收到 ±23）→ 下沿 **−13**、顶边 **+45**。给喙让 5mm、给顶盖让 6mm | 方兰 52.6 每边只剩 2.7mm 遮丑余量，四角 R5 圆角内缩 1.46mm —— 刚够，不能再小 |

**还没定**：P4 喙面板顶边的绝对 Y。目前文档里只写了"头正面下部"，没有硬数值。
进 SolidWorks 建 P4 之前必须定它，否则外罩 68 还是 58 悬着。

### 6.3 打印/喷漆的一句提醒

外罩是正脸上最大的一块面色，**必须喷**（完成度红线：看不出层纹）。
建议 **橙 PETG 打印 → 打磨 400→800→1500 → 底漆（#F26B21 同号）→ 哑光面漆（#F26B21 同号）**。
底漆面漆用同号橙，宁可比 #F26B21 略深——露底下是深色才难看，露出略深的橙面反而是"同色"。
不要用奶油色打底再喷橙：奶油透出来会发脏。

## 8. 订正：外盖不要凸台，孔深改 3.0（2026-10-02 晚）

**不用先做 D5 圆柱再挖 D3.2。** 外盖只有 4mm 厚，凸台是往腔里长的悬空特征，打印娇气、
还要在前脸上再开 4 个 Ø5.5 大通孔（漏气风险 + 多一套孔），不值。
热熔螺母本身就 3.0 长，直接压 3.0 深的平孔就够了 —— 压到底正好与贴脸面齐平。

**D5 凸台 + Ø3.0 盲孔那套是 P1 前脸的做法**（喇叭法兰 4 角：4×Ø5.5 凸台、Ø3.0×深 5.5 盲孔埋 M2），
两个零件不要混。

| 旧（错） | 新（对） |
|---|---|
| 孔 Ø3.2 × 深 2.6，正面留 1.4 | 孔 Ø3.2 × 深 **3.0**，正面留 **1.0** |
| 开口在"背面"、需要切"反侧" | 开口在**贴脸面（腔侧）**、方向**朝正面 +Z（默认方向）** |
| 螺母长 3.0 塞不进 2.6 的孔 → 会凸出 0.4 戳进 P1 脸面（干涉） | 3.0 孔吃 3.0 螺母，压到底齐平，零干涉 |

SW 做法：**转到贴脸那面（腔侧）→ 新建草图 → 4 个 Ø3.2 全圆（相对盖心 ±28）→ 切除-拉伸 →
给定深度 3.0 → 方向用默认（远离该面，朝正面走），不要点"反侧"**。
自检：等轴测看孔口在贴脸面；侧视量孔底距正面剩 1.0mm 实料。

## 9. 四角孔不行，孔位必须是「四边中点」十字（几何论证）

外盖建的时候最容易把螺母孔放到板的四角（照实物参考的四角金点）。四角放不下，三条理由：

1. **R5 圆角把角切了。** 68×68 板（以板心为原点，边 ±34，R5 圆角圆心在 ±29）：
   孔心要离 R5 圆心 ≤ 5 − 1.6 = **3.4** 才不被切到边界，所以孔心最外只能到 (±27.4, ±27.4)。
   → 角部只剩 2.2mm 到边，4mm 薄板的角上压一根 3mm 长的热熔螺母，一角悬空必崩边。
2. **角位和喇叭法兰那 4 颗 M2×8 螺丝孔只隔 7.07mm**（法兰孔在绝对 (±21,+37)/(±21,−5)），
   两个 Ø3.0/3.2 孔之间只剩约 4mm 薄壁；而且 P1 上那个位置要打 M2×10 通孔，会和法兰盲孔在同一 X/Y 上打架。
3. **十字才和 Ø48 同心对称**：四边中点 [(0,±28)/(±28,0)] 到 Ø48 孔壁 2.4mm、到盖边 6mm，料最匀，
   视觉上是"四边四颗 + 中间一只眼"，比四角更像一个面罩。

> 顺带：截图里板子看着"又扁又宽"是透视 R5 视角造成的，**不要按屏幕比量尺寸**，
> 用 SW 测量确认：板 68×68×4、圆角 R5、中心 Ø48 通、Ø52 沉台深 1.2。

## 10. P1 前脸上与外盖对接的 4 个孔（做法）

### 10.1 先锁坐标：两边共用眼心原点

P1 与 P14 **都以眼心为原点**（两步渲染的 triad 都落在 Ø48 孔心，这点已经对了），
所以 P1 上这 4 个孔的 X/Y 与 P14 的 4 个螺母孔**数值完全相同**：

| 相对眼心 | 绝对（绝对系 = 眼心为原点时同值） |
|---|---|
| (+28, 0) / (−28, 0) / (0, +28) / (0, −28) | 同上 |

原文档第 2 节的「绝对 (±28,+16)/(0,+44)/(0,−12)」是**以盖心=眼心、但外盖原点写在盖心**时的值；
 P1 若与眼心同原点，直接写 (±28, 0)/(0, ±28) 即可。**两边必须同一个数，谁改谁一起改。**

（截图里标的 36 / 23 是四角矩形布点；P1 与 P14 若都按它走也成立，
但角部 + R5 圆角崩边那条风险仍在。定死一个数再动刀。）

### 10.2 孔型与做法（**可以用异型孔向导，但必须腔侧放置**）

最终需要的孔型（沿 Z 从头到脸）：

| 位置 | 特征 | 参数 |
|---|---|---|
| 正面（外表面，Z>0） | 光孔口 | **Ø3.0 开口**，外面被 P14 压住 |
| 脸厚 2.5 | 直孔段 | **Ø3.0，完全贯穿** |
| 腔侧（腔内侧壁，Z<0） | 90° 沉头 | **Ø4.0 × 深 1.2**，给 M2 沉头螺丝头 Ø4.0×1.2 坐位（否则螺丝头凸进腔 1.2mm 可能顶到功放板/线） |

→ 也就是说：**沉头必须在腔侧、直孔必须贯穿**。这两条定死，做法随便选。

#### 方案 A（推荐）：异型孔向导，**从腔侧放一次做完**

因为终止条件选「完全贯穿」时，SW 刚好生成"**放置面侧一段 90° 沉头 + 直孔穿透**"——正好就是我们要的形状。

1. **先把模型转到腔侧朝向你**（Ctrl+6 后视 / 或手动转，让碗的内底壁对着观察者）。
2. `插入 → 特征 → 孔 → 向导`（或工具栏 Hole Wizard）。
3. **孔类型 = 机丝 (Machine Screw) → 沉头孔 (Countersink)**，标准 ISO（或 GB）。
4. **孔大小 = M2**。此时 SW 给的默认直孔直径是 **2.0**（M2 间隙孔）→ **手动改成 3.0**；
   沉头直径默认 4.1 → 保持（≈Ø4.0，M2 沉头头径）。
5. **终止条件 = 完全贯穿 (Through All)** —— 只作用于直孔段；沉头深度按 M2 标准取 1.2。
   ⚠️ 不要选"给定深度"，2.5 厚的脸 + 1.2 沉头 = 直孔段只剩 1.3，但我们要的是直孔穿透 2.5。
6. **Step 2 位置**：在腔侧面上点 4 个点 → 用智能尺寸约束到相对眼心
   **(±28, 0) / (0, ±28)**（68 方案；58 方案改 ±23）。
7. `下一步 → 完成`。预览里检查：**沉头在腔侧、正面只留 Ø3.0 小口**（点"旋转方向/Reverse"可翻转）。

#### 方案 B（腔侧找不到放置面时）：手动两步切除

1. 腔侧草图 → 4 个 Ø3.0 全圆 → **切除-拉伸 → 完全贯穿**。
2. 同草图 → 4 个 Ø4.0 全圆（或改 Ø3.0 为 Ø4.0）→ **切除-拉伸 → 给定深度 1.2 → 方向朝正面**。

#### 仍然成立的三个坑

- **绝对不能从正面（外表面）放。** 向导会把沉头开在放置面那一侧 → 沉头进正面，
  而螺丝头在腔侧根本没有坐位（头顶在 P1 腔面上）；正面那个沉坑还被外盖压住，装配才发现。
- **孔类型不要选"机丝 → 螺纹孔 (Tap)"**，那会生成 M2 螺纹线（给螺柱用的），我们要的是光孔。
- **腔侧放置面** = 抽壳后碗的**内底壁**，不是外轮廓面；选面别选错（选到正面就翻车了）。

### 10.2c 向导实拍参数订正（2026-10-02 晚，用户截图）

SW 孔向导实拍：标准 **GB**、类型 **开槽半沉头螺钉 GB/T 69-**、大小 **M3**、套合 **松弛**、
自定义 **3.00 / 4.100 / 90 度**、终止条件 **完全贯穿**。

| 项 | 截图值 | 应为 | 理由 |
|---|---|---|---|
| 大小 | **M3** ❌ | **M2** ✓ | M3 半沉头头径 ≈5.0（沉头 5.5），坐不进 Ø4.0 的沉台（顶在孔口上不去）；而且手上没有 M3 螺丝。M3×10 是**合壳（P1↔P2）**用的，别拿它顶这里 |
| 类型 | GB/T 69 半沉头 | **保持**（手上只有半沉头） | 68（沉头）与 69（半沉头）对 M2 的头径/头高**完全一样**（都是 4.0 / 1.2），以手上有啥为准 |
| 套合 | 松弛 (Clearance) | **保持** ✓ | 我们要光孔，不要螺纹线 |
| 自定义 ① 孔直径 | 3.00 | **保持 3.00**（但改 M2 后 SW 会重置成 2.0，改完要再手打回 3.0） | 杆 Ø1.6~2.0，孔 3.0 有余量；外盖螺母孔 Ø3.2 |
| 自定义 ② 沉头直径 | 4.100 | **保持**（M2 沉头头径 4.0~4.1） | 与腔侧沉台 Ø4.0 配套 |
| 自定义 ③ 角度 | 90 度 | **保持** ✓ | |
| 终止条件 | 完全贯穿 | **保持** ✓ | 只作用于直孔段，沉头按 M2 标准取 1.2 |

> 半沉头比沉头会多凸出约 0.2~0.3mm（半球顶），凸进腔内那点量无所谓，**不要为此改沉台深度**。
> 位置页要点满 **4 个点**（向导一个点生成一个孔），尺寸 (±28,0)/(0,±28) 相对眼心。

### 10.2b 装配后处理

螺丝杆 Ø2.0 插在 Ø3.0 孔里单边 1.0 缝 → 拧完打硅胶/热熔胶封（与 Ø10 过线孔同一处理）。
沉头 1.2 + 穿脸 2.5 + 咬合螺母 3.0 = 6.7 → **M2×10 沉头富余 3.3mm** ✓（M2×8 只富余 1.3，仍用 M2×10）。

### 10.3 别把这 4 个孔开到凸台上

P1 大孔周围那 4 个小圆孔（Ø3.0×深 5.5）= **喇叭法兰凸台**（M2×8 从外拧进 P1），
和对接外盖的这 4 个是两拨人、不是同一批孔，别混。

### 10.4 螺丝长度复核

## 12. 喇叭（方法兰）怎么固定到 P1 前脸 —— 正面 4 颗 M2（2026-10-02 晚补）

### 12.1 结论：外面不加任何零件

固定喇叭只有一样东西：**4 颗 M2 机丝从正面拧进 P1 前脸凸台里的热熔螺母**。
外面多出来的唯一零件是 **P14 外盖，但它不是固定件** —— 它不参与受力，只负责把方兰和
这 4 颗螺丝头遮住（这也是当初要外盖的原因）。

顺序上：先拧螺丝压法兰 → 泡棉 → 腔内装电路 → 最后扣外盖（此时 4 颗螺丝头才被吃掉）。

### 12.2 今天才发现的坑：螺丝头会把喇叭法兰顶起 1.2mm

方法兰是**贴着凸台顶端平面**压下去的（面贴式，不是沉进坑里）。而 M2 沉头/半沉头的
头径 4.0、**头高 1.2**。

如果螺丝头直接坐在凸台顶端平面上：

→ 螺丝头凸出凸台顶端 **1.2mm** → **法兰被顶起 1.2mm，压不到底**。

后果不是好看不好看，是功能性的：
1. 法兰与脸面之间的 **2mm 闭孔泡棉环压不实** → 气封失败 → 漏气、低频丢、可能啸叫
   （这正是当初把"壳即腔"方案排除的原因，别在这里自己漏回去）；
2. 法兰四角翘起，外盖（同样贴在脸外表面）也跟着不平，橙外盖边缘会翘缝。

**解法：凸台顶端开一道 Ø4.0 × 深 1.2 的 90° 沉台**，把螺丝头沉进去，
沉台底平面 = 新的贴合面 → 螺丝头与凸台顶端齐平 = 法兰能压死。

> 判据（记牢）：**法兰贴合面必须是凸台顶端那个平面本身，不是凸台顶端上面 1.2mm 的空气。**
> 所以只要用沉头/半沉头，凸台顶端就一定得有沉台。用盘头/圆头则更糟（凸 1.5~2mm），别选。

### 12.3 参数（P1 前脸 4 个凸台，坐标相对眼心、与绝对同值）

| 项 | 值 | 说明 |
|---|---|---|
| 孔位（相对眼心） | **(+21,+21) / (−21,+21) / (+21,−21) / (−21,−21)** | 见 §12.6 待量；对角 42×42 |
| 凸台 | **Ø5.5 × 高出脸面 5.5** | 从脸外表面往外长 |
| 顶端沉台 | **Ø4.0 × 深 1.2**（90°） | 沉头坐位，与凸台顶端齐平 → 法兰贴合面 |
| 沉台底盲孔 | **Ø3.0 × 深 4.3** | 吃热熔螺母 |
| 孔底之内 | 孔底距脸外表面 5.5 − 4.3 = **1.2**，再进脸厚 2.5 → **背后留 3.7 实料** ✓ 绝不会穿 |
| 热熔螺母 | **M2×3×3**，压进 Ø3.0×4.3（吃满 3.0，留 1.3 空） | 已有 50 个，够 |

### 12.4 螺丝长度复核 + 采购（这条会卡住你）

1.2（沉台）+ 4.3（盲孔）+ 3.0（咬合螺母）= **8.5**

| 螺丝 | 判定 |
|---|---|
| M2×5（手上现有） | ❌ **差 3.5mm，绝对拧不进去**，还会把螺母顶歪 |
| M2×8 | 富余 0.5，太险 |
| **M2×10** | 富余 **1.5** ✓ → 定 M2×10 |

**采购合并算一次**：法兰 4 颗 + 外盖 4 颗 = **M2×10 至少 8 颗（买 10 颗留余）**。
头型 68（沉头）/ 69（半沉头）均可（对 M2 头径头高一样），**以手上有货为准**。

### 12.5 与外盖的关系（别拧反了）

- 法兰这 4 颗 M2×10 是**从正面拧（螺丝头在喇叭正面）**，然后被 P14 外盖吃掉；
- 外盖那 4 颗 M2×10 是**从腔内往里拧（螺丝头在腔内）**，吃完从后口伸进去。
- 两拨人、两个方向、各 4 颗，**一共 8 颗 M2×10**，别只买 4 颗。

### 12.6 待量：法兰四角的孔距

上表孔位 (±21, ±21) 是按 **52.6 方框法兰、四角孔距中心约 21** 估的（不是实测）。

  十字孔距法兰孔最近 22mm（(±28,0) 到 (+21,+21) = √(7²+21²) = 22.1），有 4mm 余量可吸收少量偏移。

### 12.7 与 §10.3 的关系

§10.3 说的"别把对接外盖的 4 个孔开到凸台上"仍然成立 —— 现在这一节更明确：
