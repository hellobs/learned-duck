台面接线 · 手把手

Learned Duck 单喇叭版 · 依据 docs/17_电路系统设计与接线.md · 2026-10-03
三条铁律，贯穿全程
  1. 断电再动手。插拔任何线之前，12V 适配器先拔掉。带电插拔最容易烧端子。
  2. 不凭线色判极性。红不一定是正、黑不一定是负。万用表量过再接。
  3. 功率件先测电压再接负载。功放、降压模块这类板子，通电后先量输出对不对，对了才往上挂喇叭 / ESP。

0 · 开工前的桌面 先把这堆东西摆齐再动手

工具

  • 万用表（必须有） —— 本手册每一步都靠它判生死，没它就是盲接
  • 电烙铁 + 焊台、斜嘴钳、镊子、热缩管、绝缘胶带
  • 手机（当蓝牙音源）

还没买齐也不要停——阶段一只要 适配器 + 功放 + 喇叭 三样就能开工。

阶段 1 · 功放链路 今晚必做 · 只出声音就算过

这是整套里最难的一段。台面上做，不装进任何壳。

步骤 0 · 目检并拍照

把功放板翻过来看清楚每个端子的丝印，拍照存着。典型丝印：

12V+  ｜  GND  ｜  OUT L+   OUT L-  ｜  OUT R+   OUT R- （有些板子写 V+ / V- / L / R，按实际丝印认，别照抄）

顺便看两件事：① 有没有 AUX / 3.5mm 口 ② 有没有 安装孔（关系到身壳里它是拧的还是粘的）。

步骤 1 · 量适配器空载

  • 万用表打 直流电压 20V 档，表笔插 V+ / COM。
  • 黑笔接适配器输出外圈，红笔接中心针（DC 公母座）。
  • 读数应在 12.0 ~ 13.5 V。
停手点：低于 11 V 或高于 14 V —— 别接板子，先查适配器。

步骤 2 · 只给功放板供电，先不挂喇叭

适配器 +  →  功放 12V+
适配器 −  →  功放 GND
  • 通电，万用表并到功放板 12V+ 与 GND 之间，量电压。
  • 读数应与步骤 1 基本一致（差 0.2 V 内）。
  • 板子若有指示灯，此时应亮。
停手点：板上读数明显低于适配器输出（压降大 = 板子可能已经短路）；或闻到焦味 / 异常发热 → 立刻断电，别再加喇叭试。

步骤 3 · 接喇叭

功放 OUT L+  →  喇叭 一端
功放 OUT L-  →  喇叭 另一端
只接 OUT L 一路。 OUT R 就那么悬着。

两块输出并到同一只 4Ω 喇叭上 = 4Ω∥4Ω = 2Ω，负载阻抗掉一半，功放过流保护甚至烧板。想双声道就得配两只喇叭。

  • 喇叭必须架起来悬空（垫两支笔、或放在空盒子上）。趴桌面上振膜贴桌面，会闷、会跟着桌面共振。
  • 引线用 24AWG 跳线即可，短线，别留一大坨垂着。

步骤 4 · 通电出声

  1. 接好喇叭后最后再通电。
  2. 手机开蓝牙搜设备 → 连名字像 XY-xxxx / BT-…… 的那一个 （不是 ESP32，ESP32 现在是裸板根本不广播）
  3. 连上后先别放歌，把手机音量调到 20。
  4. 放歌，音量旋钮从最小往慢慢推。
  5. 听到声音 = 音频链路闭环 ✅
完成判据：手机能连上并出声，且没有明显嗡声/滋滋声。

没声音？按这个顺序排，别乱拆

顺序查什么怎么查
112V 有没有到板子上万用表量板上 12V+↔GND（步骤 2 复测）
2蓝牙连上了吗手机蓝牙列表里设备名在不在、状态是不是已连接
3喇叭线接对了吗OUT L 的 +/− 有没有接反（接反只是相位反，不至于没声，重点是别接到 OUT R）
4音量板载旋钮是不是最小、手机音量是不是太小
5喇叭本身直接给喇叭接 12V 直流试一下（⚡短时间、低音量）：有"啪啪"声说明喇叭是好的

阶段 2 · 降压模块单测 不接任何负载，先看它对不对

这一步的判据只有一条：输出 5.0 ~ 5.3 V。量不到或明显偏离，就不要往 ESP32 / 灯板上接——那两块板子没有反接保护，接错电压直接烧。

先认清两个焊盘

这类 mini 降压模块通常只有 2 个邮票孔，但丝印各不相同。以实物为准：

丝印长这样含义接法
IN+ / IN- 或 VIN + / VIN -标了输入输出两对进 12V，出 5V，别接反
V+ / G 或 VCC / GND只标一个电压⚠️ 必须看背面丝印 / 卖家说明，不确定就查电压

万用表怎么分辨：输入侧应该对 12V 正极呈二极管态（0.4~0.6 V 压降）；输出侧对 5V 也是二极管态。用二极管档量两组，能区分出哪对是输入。

步骤

  1. 断电接线：IN+ ← 12V+、IN- ← GND。
  2. 通电，空载量输出 OUT+ ↔ OUT-。
  3. 读数 5.0 ~ 5.3 V → 这块模块是好的。
停手点：输出 > 5.5 V（会烧 ESP32 / 灯板）、< 4.8 V（带不动灯）、或输出 0 V（模块坏了或接反了）。

阶段 3 · 先让灯亮 绕开降压，用 USB-C 跑通固件

为什么先这么绕？降压模块单独测过了、ESP 也能单独跑，把两件难事拆成两半排风险。等两边都过了，再合到一起 —— 一起上电出问题，你根本不知道是谁的锅。

硬件连线

ESP32 GPIO4  ──[330Ω]──  灯板 DIN
ESP32 5V / VCC  ──  灯板 VCC（或 5V）
ESP32 GND  ──  灯板 GND
  • ESP32 用 USB-C 数据线接电脑供电，不要用板上 3V3 给灯供电（3.3V 带不动，且 WS2812 亮度会塌）。
  • 330Ω 电阻焊在 GPIO4 → DIN 这段的中间，离灯板 DIN 焊盘 5~10 mm。它是给信号线上冲的，不是随便挂上去。
  • 灯板如果有两块（5×5），第一块 OUT 接第二块 IN，串成一条链。

固件（Arduino IDE）

  1. 开发板管理器搜 esp32，安装 Espressif Systems 的包。
  2. 开发板选 ESP32C3 Dev Module。
  3. 库管理器搜 Adafruit NeoPixel（或 FastLED），装一个。
  4. 先跑板载示例（File → Examples → Adafruit NeoPixel → NeoPixel simplest）验证通路，再写自己的。

亮度上限：180 / 255。头顶方案只点中间一行 10 颗，电流 0.42 A，对降压 1.6 A 持续限还有 3 倍余量，可以放开。

完成判据：灯板亮起 10 颗（头顶那排），颜色是你设的，不乱闪。

阶段 4 · 合并到 5V 系统 降压替代 USB，双件合一

必须先拔掉 USB-C，否则两路 5V 顶在一起。
降压 OUT+  ──  灯板 VCC  （单独一路 24AWG，不与 ESP 共用）
降压 OUT+  ──  ESP32 5V / VCC
降压 OUT−  ──  灯板 GND
降压 OUT−  ──  ESP32 GND
  • 5V 侧只需确认：降压的 OUT− 和 IN− 在模块内部本来是通的（非隔离 DC-DC），所以 12V 地和 5V 地自动共地，不用额外跨接。
  • 上电顺序：先看降压输出对不对 → 再看 ESP 电源灯 → 最后看灯。
完成判据：拔掉 USB 后，灯仍然正常亮（说明 5V 真的由降压供上了）。

阶段 5 · 12V 总线 + 全机台面联调 把开关和 DC 座加进来

5.1 先搞清楚 DC022 的极性

DC 座是「中心针 + 外壳圈」。多数是中心正、外壳负，但也有反的。

  • 把适配器插头插进 DC 座（不接任何其他线），万用表量：中心针 ↔ 外壳圈。
  • 黑笔接外壳、红笔接中心，读数为正 → 中心是正极。
停手点：接反直接给功放板灌反电压。量完再往下走，这一步不许跳。

焊与安全 · 十条红线

  1. 烙铁温度 320~350 ℃，焊 2~3 秒就把烙铁移开，靠锡流动，不要按着不动。
  2. 每个焊点都要有光亮的锡润湿，哑淡的锡球是虚焊，会接触不良。
  3. 焊完先不插电，用放大镜/手机镜头看一遍每个焊点有没有连锡（短路）。
  4. 裸露线头一律热缩管或绝缘胶带包死。短路 3 秒就能烧板。
  5. 通电时手不要在板上悬着，尤其是降压模块发热区。
  6. 降压模块、功放板不能长时间满载 2A，台面测试阶段音量别开满、别连着听几小时。
  7. 12V 总线全程用 20AWG，清单里那批 24AWG 只给 5V / 信号用。
  8. 喇叭线悬空架好，别贴桌面。
  9. 调试期间别接金属桌面的螺丝刀一起碰两块板 —— 随手一碰就短路。
  10. 第一次上电请 有人在旁边，闻味不对立刻断电。
