# firmware/ · 固件

ESP32-C3-Zero（ESP32-C3FH4）的 Arduino 固件。

## 当前状态：尚未提交

固件在总装阶段编写。当前已确定的只有**接口设计**——目的很明确：**日后要扩展，只需新增，不必返工。**

## 计划结构

```
firmware/learned_duck/
├── learned_duck.ino    主程序
├── modes.h             灯光模式表 {名称, 函数指针}
├── audio.h             音频输入与律动
└── config.h            亮度上限、引脚定义
```

## 已确定的设计约束

| 项 | 值 | 原因 |
|---|---|---|
| 全局亮度上限 | **≤ 120 / 255** | 50 颗 WS2812B 全白满亮约 3.0 A，而降压模块额定只有 3 A |
| 灯阵供电 | 单独走一路 | 不与 ESP32 共用 24AWG 跳线 |
| 天线净空 | 天线端 10 mm 内无金属、不贴壳壁 | 否则蓝牙与 WiFi 直接衰减 |
| 开发环境 | Arduino IDE + ESP32-C3 开发板库 | 课程要求 |

## 预留接口（当前不实现）

刻意留好的三个「接缝」，成本极低，但让 v1.0 可以纯增量开发：

| 预留项 | 现在怎么做 | 日后怎么加 |
|---|---|---|
| **模式表架构** | 建 `{名称, 函数指针}` 表，先只填 3 项 | 加模式 = 写一个函数 + 表里加一行。主程序、按钮逻辑、限流全部不动 |
| **NVS `seed`** | 预留字段，当前写死固定值 | 改成随机生成 → 启动光纹即变成每台唯一 |
| **腿部姿态** | 关节按 **12 档定位齿盘**设计，可手动摆放 | 刻姿态对齐线即可；改用舵机时轴孔 Ø3.2 就是安装基准 |

## 灯光模式

当前实现三种，由 Ø10 按钮循环切换：**待机呼吸** / **音乐律动** / **流光扫描**。
